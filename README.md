# Pepe Nero Ristorante — Experiência Digital & Identidade de Marca

Demonstração digital e proposta de modernização da identidade visual para o **Pepe Nero Ristorante**, tradicional restaurante italiano fundado em 2010 no Centro Histórico de Planaltina-DF.

---

## 🏛️ Sobre o Projeto

Este projeto foi concebido para elevar a presença digital do Pepe Nero com uma experiência visual sofisticada, navegação intuitiva e padrão de alta gastronomia, preservando os elementos afetivos e históricos que consolidaram a marca desde 2010.

### 🎨 Identidade Visual & Redesign da Marca
- **Evolução Conceitual:** Transição da tipografia script cursiva informal para uma construção lapidar clássica romana de alto contraste inspirada na gastronomia de Modena (Emília-Romanha, Itália).
- **Suíte de Marcas em Vetor SVG:**
  - *Logo Principal (Medallion Emblem)* — Aplicação nobre com filetes em ouro antigo e ornatos de grãos de pimenta (*pepe nero*).
  - *Logo Horizontal* — Para cabeçalhos, barras de navegação e papelaria.
  - *Versão Compacta / Monograma (PN)* — Para fotos de perfil (Instagram, WhatsApp) e favicons.
  - *Monocromáticos Preto & Branco* — Para carimbos, notas e gravações.
- **Paleta de Cores:** *Rosso Nobile* (`#420A12`), *Nero Profondo* (`#0E0C0D`), *Oro Antico* (`#C5A059`), *Oro Chiaro* (`#F4E2BD`) e *Crema Toscana* (`#F7F3EB`).

### ✨ Funcionalidades da Aplicação
- **Cardápio Digital Interativo:** Categorias completas (Antipasti, Massas Artesanais, Pizzas de Longa Fermentação, Risotos, Carnes e Sobremesas), pesquisa em tempo real, modal de harmonização e consulta direta via WhatsApp.
- **Assistente Inteligente de Reservas:** Configurador de data, horário, número de convidados e ocasião com formatação de mensagem direta para o WhatsApp oficial `(61) 99553-0777`.
- **Galeria Editorial & Lightbox:** Curadoria fotográfica em alta resolução com navegação ampliada.
- **Localização & Horários:** Integração com Google Maps, direções de rota (Waze e Maps) e dados do Setor Tradicional de Planaltina-DF.
- **Showcase Interativo da Marca:** Comparativo antes/depois, download de vetores SVG e cópia de códigos HEX diretamente pela interface.

## 🚀 Como Executar o Projeto Localmente

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/davifeels/PepeNero.git
   cd PepeNero
   ```

2. **Instalar as dependências:**
   ```bash
   npm install
   ```

3. **Iniciar o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Gerar build de produção:**
   ```bash
   npm run build
   npm run preview
   ```
